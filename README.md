# E-commerce Business Performance Analysis 

## Project Overview 
An end to end data analytics project exploring the brazilian E-Commerce Public dataset by Olist. 

## Objectives 
- Analyse revenue 
- Identify top-performance product categories 
- Understand customer purchasing behaviour 
- Evalaute order cancellations 

## Tools & Technologies 
- PostgreSQL 
- SQL 
- Python 
- Pandas 
- NumPy 
- Matplotlib 

## Project Structure 
- data/ : Dataset files 
- sql/ : SQL queries 
- notebooks/ : Python analysis 
- visulastions/ : Genereated Charts
